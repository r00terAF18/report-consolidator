# Report Consolidator GUI

Themed PySide6 desktop app packaged with Nuitka and uv.

## Themes
- **Synthwave**: Neon magenta, cyan, and deep purple palette.
- **Liquid Glass**: Translucent dark glass gradients with frosted accents.

## Development
\`\`\`bash
uv sync
uv run python src/my_qt_app/main.py
\`\`\`

## Compile Standalone Binary
\`\`\`bash
uv run python build.py
\`\`\`
The compiled executable will be in \`dist/main.dist/\`.
